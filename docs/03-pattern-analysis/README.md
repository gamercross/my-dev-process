# 3단계: 패턴 분석

> 상태: ⬜ 미착수

2단계에서 확정된 요구사항을 놓고, 어떤 알고리즘 패턴(알고리즘 트랙) 또는 아키텍처 패턴
(프로젝트 트랙)으로 풀지 후보를 비교·선택하는 단계.

## 이 단계에서 채울 내용 (예정)

- 후보 패턴 2~3개 나열 및 트레이드오프 비교
- [`docs/catalog/patterns.md`](../catalog/patterns.md)에서 유사 패턴 검색 결과
- **패턴 선택 근거 기록**: 왜 A 대신 B를 선택했는지 한 줄이라도 남기기 (7단계 회고에서 유용)
- 선택된 패턴을 4단계로 전달

## 이 프로젝트(워크플로우 시스템)에 적용할 다음 결정 사항

- 이 시스템을 순수 파일/폴더 구조로 유지할지, Claude Code 커스텀 스킬(SKILL.md)로 만들지
- 패턴 카탈로그 검색을 수동 grep으로 할지, 태그 인덱스 파일을 따로 둘지
