제목: Two Sum
출처(플랫폼, 문제번호): LeetCode #1
시나리오(원문 요약): 정수 배열과 목표값이 주어질 때, 합이 목표값이 되는 두 인덱스를 찾는다.
입력 형식 + 제약조건(수학적 표기, 예: 1 ≤ n ≤ 10^5): nums(정수 배열, 2 ≤ len(nums) ≤ 10^4), target(정수)
출력 형식: 인덱스 두 개 (배열)
예제 입출력(최소 1쌍): nums=[2,7,11,15], target=9 → [0,1]
태그(3단계 패턴 분류와 연결): 해시맵, 투포인터후보
상태(미착수 / 분석중 / 풀이완료 / 복습필요): 분석중
